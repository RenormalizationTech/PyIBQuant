# Changelog

## 0.1.0.dev1

Development snapshot; no stable release is implied.

- Add IBKR historical equity/ETF data with fixed bounds, sequential paging,
  pacing, explicit partial failures, exports and optional Parquet caching.
- Add an optional Yahoo Finance daily US stock/ETF preview without TWS.
- Add frozen datasets/collections, integrity fingerprints, quality reports,
  calendar assertions and exact-timestamp alignment.
- Add returns/SMA helpers, descriptive daily correlations and intraday increment studies.
- Add daily equity and selected intraday option backtests with explicit synthetic
  next-open execution, costs and retained input/settings provenance.
- Add a strategy-callback simulator with completed-bar views, shared USD cash,
  whole long quantities, market-order cancellation and replaceable fill models.
- Add option discovery, selected-option history, stock/option quote snapshots and
  independently owned streams with explicit gap/generation evidence.
- Add read-only paper accounts, durable journals, account/strategy reports,
  bounded experimental orders, exact-ID cancellation and restart reconciliation.
- Add versioned local settlement funding, owned-position exits, bounded SMA
  equity/option runners and explicit cross-session recovery.
- Add user guides, an offline walkthrough, Yahoo examples, a strategy lab and a
  searchable GitHub Pages documentation build with left-side navigation.
- Add a backtesting guide and an intraday SPY range-reversion example with fixed
  and scaled position rules.
- Separate contributor instructions from user documentation and remove personal
  session narratives and actual run/check identities from current public files.
